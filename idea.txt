THE PRODUCT
SecondLook — a Manifest V3 Chrome extension: a security suite framed asquality-of-life features. Four pillars, ten modules:

Pillar 1 — Know Before You Go (links & navigation)

Link Sniper (+ Email Link Inspector + Safe Mode) — Analyzes links beforeclick (including links in Gmail/Outlook emails), revealing the truedestination and flagging suspicious URLs. Risky sites open in Safe Mode:scripts and active content blocked.
Redirect Detective — Traces and visualizes a link's full redirect chain,warning when the user is silently bounced between unexpected domains.
Tab Guard — Flags sites that unexpectedly spawn tabs/windows/pop-up storms;auto-closes or quarantines them, with undo.
Pillar 2 — Trust What You See (page & search integrity)4. Trust Badge — On Google/Bing/DuckDuckGo results: highlights the official, verified domain for the searched brand; removes or tombstones sponsored look-alikes and reveals where they pointed.5. Ghost Click Blocker — Neutralizes invisible overlays and hijack elements so clicks fall through to real content, without breaking legitimate sites.6. Fake Download Button Detector — Detects "Download" buttons that actually trigger redirects, ads, or unwanted downloads.

Pillar 3 — Guard What You Share (forms & files)7. Form Guardian — Shows what a form submits and where it's really sent ("You're on shop.com, but this form sends your email to tracking-service.com"); hard-blocks cross-origin password/card submissions.8. Download Guard — Inspects downloads: dangerous extensions, double extensions (invoice.pdf.exe), misleading names, and content/extension mismatch via magic-byte sniffing.

Pillar 4 — Security That Runs Itself (hygiene & comfort)9. Cookie Tamer — Auto-dismisses cookie banners by clicking "Reject All"/ "Essential Only" (NEVER clicks Accept); one-click wipes current-site cookies while preserving login cookies.10. Webcam/Mic Indicator — Persistent glanceable light whenever a site uses camera/microphone; one click shows which tab.

NON-NEGOTIABLE DESIGN PHILOSOPHY
Tagline: "We don't tell you that the internet is dangerous. We tell you whensomething deserves a second look." This governs every user-facing decision:

Verdict vocabulary is fixed and calm: CLEAR ("Nothing unusual"),SECOND LOOK ("Worth a second look —" + one plain-language reason),INTERCEPTED (only for high-confidence credential/file exfiltration;always reversible).
Every warning card = verdict + one-sentence WHY in plain language + onerecommended action. No jargon without inline explanation.
Never more than one visible warning per event; aggregate signals.
Every intervention has an Undo; every module is per-site disableable ANDglobally toggleable from the popup.
Nudge, don't block: under ambiguity, inform instead of interrupt.
Local-first: all analysis on-device, zero telemetry, no remote code, no eval.
Bundled assets only (libraries, brand lists, icons).

MODULE TOGGLES — "OFF MUST MEAN OFF"
Every module has a master on/off switch (default ON), persisted inchrome.storage.local under a single settings map; per-site disables composewith it (module on + site not disabled).
Architecture rule: the manifest's static content_scripts field containsNO module code. All module content scripts are registered at runtime viachrome.scripting.registerContentScripts (from a settings-driven bootstrapat install/startup; registrations persist across restarts — guard againstduplicate-registration errors) and UNREGISTERED viaunregisterContentScripts when the user toggles a module off.
Toggling a module off must also message all open tabs to undo thatmodule's page effects: remove annotations/cards/badges, restorepointer-events (Ghost Click Blocker), remove that module's DNR sessionrules (Safe Mode), and stop observing. SW event listeners for a disabledmodule early-return on a settings check.
The "Pause everything" master switch disables all modules in one actionand clears all session-side effects; toolbar icon switches to a clearlydimmed/paused state.
TECHNICAL GROUND RULES (MV3 reality — violations = wrong answer)
Manifest V3 only. Blocking = declarativeNetRequest ONLY (use SESSION rulesfor Safe Mode, scoped to a single tabId via ruleCondition.tabIds).webRequest is allowed for OBSERVATION only.
Service worker is ephemeral: no in-memory state across events. Persist tochrome.storage.session (runtime) / chrome.storage.local (settings);re-hydrate on startup; use chrome.alarms for periodic work.
Content scripts: ISOLATED world by default; world "MAIN" where page JS mustbe hooked (getUserMedia, clipboard), injected at document_start.
Minimal permissions, each justified in a table (storage, tabs, scripting,downloads, cookies, alarms, contextMenus, declarativeNetRequest,webRequest-observe; host_permissions + mail.google.com +outlook.live.com + the three search engines — justify each).
Plain modern JavaScript, no build step, no framework, no bundler. Each filemust work as-is when saved at its given path. Provide SVG icons + exportinstructions (16/32/48/128), including toolbar icon states (default,alert, paused, camera-active).
